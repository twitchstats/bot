Faceit (для !эло)

Нужен бесплатный API-ключ (тип «Server-side») с developers.faceit.com/apps, чтобы команда !эло могла запросить рейтинг и статистику за сегодня.
Faceit Data API не отдаёт CORS-заголовки браузеру — прямой запрос из этой страницы всегда будет заблокирован. Нужен маленький бесплатный прокси (Cloudflare Workers, 2 минуты настройки) — код и инструкция ниже в чате.
Приоритет поиска: Player ID → Steam ID64 → никнейм. Если указан Player ID — бот берёт данные напрямую по нему (быстрее, без поиска по нику). Расширенная статистика: faceitanalyser.com/account/ddrt/cs2 — ссылка на неё доступна в шаблоне через переменную {statsLink}.
